# VSReacT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A React+TypeScript UI framework ("VSReacT") for JUCE plugins — custom C++ renderer, QuickJS runtime, Yoga flexbox, Tailwind-style classes — proven by rewriting StashTrack's full UI in React.

**Architecture:** React app runs in QuickJS-ng inside the plugin; a custom react-reconciler host config emits JSON mutation batches over a C bridge; C++ maintains a shadow tree, lays it out with Yoga, and paints with juce::Graphics. TextInput wraps a real juce::TextEditor; NativeView mounts registered juce::Components (waveform). Spec: `docs/superpowers/specs/2026-07-16-vsreact-design.md`.

**Tech Stack:** JUCE (H:/code/VSTs/JUCE), quickjs-ng (pinned tag, static lib), Yoga (copied from vendored react-juce), react 18.3.1 + react-reconciler 0.29.2, TypeScript, Bun (bundling + tests), CMake/VS2022.

**Environment facts:** Windows, VS 2022 generator. `bun` 1.3.14 on PATH. StashTrack is a *nested git repo* — framework commits go to the outer VSReacT repo, StashTrack commits to its own repo. Both on branch `posthog-code/vsreact`. No build dir yet: first configure is `cmake -S StashTrack -B StashTrack/build-vs -G "Visual Studio 17 2022" -A x64`.

## Locked contracts (used by every task — keep names EXACT)

### Mutation protocol (JS→C++), JSON array of ops via `globalThis.__vsreact_flush(json)`

```json
[
  ["create", 1, "view"],          // types: view | text | rawtext | image | textinput | native
  ["setProps", 1, {"style": {...}, "hoverStyle": {...}, "activeStyle": {...},
                    "listeners": ["click","mouseenter"], "text": "…",
                    "nativeId": "waveform", "value": "…", "placeholder": "…",
                    "cursor": "pointer"}],
  ["appendChild", 0, 1],          // 0 is always the root container
  ["insertBefore", 0, 2, 1],
  ["removeChild", 0, 1],
  ["setText", 3, "new text"]      // rawtext fast path
]
```

### C++→JS entry points (globals defined by the JS bundle)

- `__vsreact_dispatch(kindJson)` — `{"kind":"event","nodeId":5,"type":"click","payload":{}}`
  or `{"kind":"native","name":"status","payload":{...}}` or `{"kind":"timer","id":7}`

### C functions registered into QuickJS by C++

- `__vsreact_flush(json: string): void`
- `__vsreact_nativeCall(name: string, argsJson: string): string` (sync JSON result)
- `__vsreact_log(level: string, msg: string): void`
- `__vsreact_setTimer(id: number, ms: number): void`, `__vsreact_clearTimer(id: number): void`

### Resolved style keys (flat object; JS resolver output = C++ parser input)

Layout (→Yoga): `flexDirection("row"|"column")`, `flex`, `flexGrow`, `flexShrink`,
`flexBasis`, `flexWrap("wrap")`, `alignItems`, `alignSelf`, `justifyContent`
(yoga enum strings: `"flex-start"|"center"|"flex-end"|"space-between"|"space-around"|"stretch"`),
`gap`, `rowGap`, `columnGap`, `width`, `height`, `minWidth`, `minHeight`, `maxWidth`,
`maxHeight` (number px or `"NN%"`), `padding`+`paddingTop/Right/Bottom/Left`,
`margin`+`marginTop/Right/Bottom/Left`, `position("relative"|"absolute")`,
`top/right/bottom/left`, `overflow("hidden")`, `aspectRatio`.
Paint: `backgroundColor` (`"#rrggbb"`/`"#rrggbbaa"`), `borderColor`, `borderWidth`,
`borderRadius` + `borderTopLeftRadius/borderTopRightRadius/borderBottomLeftRadius/borderBottomRightRadius`,
`opacity` (0-1), `shadowColor`, `shadowRadius`, `shadowOffsetY`.
Text: `color`, `fontSize`, `fontWeight("bold"|400..900)`, `textAlign("left"|"center"|"right")`,
`lineHeight` (px), `letterSpacing`.

### TS public API (`@vsreact/core`)

```ts
export { View, Text, Image, TextInput, NativeView } from "./primitives";
export { render } from "./render";
export { native } from "./native";        // native.call(name, args?): any; native.on(name, cb): () => void

```

All primitives accept `className?: string`, `style?: Style`, `onClick/onMouseEnter/onMouseLeave/onMouseDown/onMouseUp`.
TextInput adds `value?`, `defaultValue?`, `placeholder?`, `onChange(v: string)`, `onSubmit(v: string)`, `onFocus`, `onBlur`.
NativeView adds `nativeId: string`. Text children must be strings/numbers.
