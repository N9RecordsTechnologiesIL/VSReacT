# 0.0.26 — closing the FAQ honest-gaps list

Design for the five gaps named in the FAQ `#gaps` section as of 0.0.25, decided
autonomously per Dave's instruction ("take care of what's left… go for 0.0.26").
Dave pre-decided: text is non-selectable by default with per-text opt-in; the
WebP approach was left open.

## 1. WebP decoding — vendor libwebp (decode-only)

- `third_party/libwebp/` (v1.6.0, BSD-3-Clause): `src/dec`, decode half of
  `src/dsp`, decode half of `src/utils`, public `src/webp` headers. Same
  vendoring pattern as yoga/quickjs-ng.
- New static lib target `vsreact_webp` in `vsreact/CMakeLists.txt`
  (explicit decode source list, PIC on, no `WEBP_USE_THREAD` → no pthread
  dependency on Linux). Linked `INTERFACE` into the module like `qjs`.
- `Painter::decodeWebPImage(data, size)`: sniff `RIFF….WEBP`, `WebPDecodeRGBA`,
  copy into a `juce::Image` (ARGB) via `setPixelColour` (premultiplies).
  Hooked into both image paths: file loads (when `ImageCache::getFromFile`
  fails and the header sniffs WebP → hash-cached like data URIs) and
  `decodeDataUriImage` (fallback after `ImageFileFormat`).
- Static WebP only (lossy VP8 + lossless VP8L + alpha). Animated WebP decodes
  its first frame at best — documented as out of scope (needs demux).

## 2. blur / backdrop-blur — stack blur + opt-in buffered painting

- `Blur.h/cpp`: in-place ARGB stack blur (Mario Klingemann's algorithm),
  `vsreact::stackBlur(juce::Image&, int radius)`.
- `blurRadius` (CSS `filter: blur()`): paintNode renders the node + subtree
  into an offscreen image padded by `2*radius`, blurs, composites. Skipped
  re-entry via an internal flag so the offscreen pass paints normally.
- `backdropBlurRadius` (CSS `backdrop-filter: blur()`): RootView detects
  backdrop nodes in the tree; if any exist it paints the whole tree into an
  ARGB frame buffer and blits. The painter carries an optional canvas pointer;
  a backdrop node snapshots the buffer region under its frame, blurs it, and
  draws it clipped to its rounded path before its own background.
- Limitations (documented): backdrop samples the untransformed frame; inside
  a transparency layer it sees the buffer beneath the layer.
- tw: `blur-none/sm//md/lg/xl/2xl/3xl` = 0/4/8/12/16/24/40/64 px sigma-ish
  radii (web values), `blur-[n]`, `backdrop-blur-*` same scale.

## 3. Text selection — opt-in per text, native highlight + clipboard

- Wire format: style key `userSelect: "text"`. Sugar: `<Text selectable>`
  (prop maps to the style key in primitives), tw `select-text` / `select-none`.
  Default stays non-selectable — no code needed for that.
- `TextSelection.h/cpp`: builds per-character boxes by mirroring
  `Painter::paintText`'s TextLayout construction (font, wrap width,
  lineSpacing, vertical centring, textTransform applied first). Run
  `stringRange`s map glyphs→characters (1:1 approximation; ligature drift
  acceptable). Exposes `charIndexAt`, `selectionRects`, `wordRangeAt`.
- Node carries `selStart/selEnd` (view state, like `scrollY`). RootView owns
  one active selection: mouseDown on selectable text (only when no drag
  listener claimed the gesture) anchors it, drag extends, dblclick selects the
  word, click elsewhere/Escape clears, Ctrl/Cmd+C copies the *visible*
  (post-textTransform) substring via `SystemClipboard`.
- Painter draws highlight rects (default `#3390ff59`, override with style key
  `selectionColor`) under the glyphs. Hover shows I-beam over selectable text.
- Selection copy is plain text of one node at a time (no cross-node ranges) —
  documented.

## 4. CSS transitions + animate-* — JS engine, zero C++

- `transitions.ts`: one shared 16 ms driver (host Scheduler timer) for all
  animated nodes. hostConfig's `applyProps` consults it: if the next style
  carries `transitionDuration > 0`, the engine diffs animatable keys
  (numbers + `#rrggbb(aa)` colors; `transitionProperty` optionally filters),
  starts from the *currently displayed* (mid-flight) values, and each frame
  re-queues the full payload with interpolated style (setProps replaces
  wholesale, so partial patches would drop listeners). Ends exactly on target.
- Presets via `animationName`: `spin` (rotate 0→360, 1s linear, loops),
  `pulse` (opacity 1→0.5→1, 2s), `bounce` (translateY dip, 1s). Duration
  override: `animationDuration`. Loops run until the class is removed or the
  node unmounts (`detachDeletedInstance` cancels).
- Honest limit (documented): native-side hover/active/focus merges don't
  transition — animate hover via onMouseEnter state if needed.
- tw: `transition` (opacity/colors/transform default set), `transition-all/
  opacity/colors/transform/none`, `duration-*`, `delay-*`, `ease-linear/in/
  out/in-out`, `animate-spin/pulse/bounce/none`.

## 5. Horizontal scroll — scrollX everywhere scrollY is

- `Node.scrollX`, `contentWidth()`, `maxScrollX()`;
  `accumulatedAncestorScroll()` → `Point<float>` (call sites updated).
- Wheel: `wheel.deltaX` scrolls X; Shift+vertical-wheel maps to X (web
  convention). Wheel event payload gains `dx`.
- Painter translates by (−scrollX, −scrollY); horizontal thumb along the
  bottom edge when X overflows. Hit test shifts child positions by both axes.
- JS: `scrollLeft` prop (mirrors `scrollTop`), tw `overflow-x-scroll` /
  `overflow-x-auto` / `overflow-auto` → `overflow: "scroll"` (axes activate
  by actual overflow, CSS `auto` style).
